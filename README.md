# Un*locke_d Twitter Clone

A fully open source Twitter clone made by hand over 6000 lines of code free to use

Links:
- Repository: https://github.com/GameStashOfficial/twitter-clone
- Issues: https://github.com/GameStashOfficial/twitter-clone/issues
- Official site : https://Xapp6.b-cdn.net/index.html

---

## Features

- **School Unblocked:** Bypass Goguardian,Linewise,etc
- **Free accounts** Every account gets 1gb of storage and unlimited messages and posts
- **Fast Loading:** Lazy looders everywhere to improve the site performance
- **Open Source:** Free to use, modify, or customize.
